# Standard artwork for Picture Flow mods

These are the seventeen images Egle draws by default, exported as PNG with the transparency already in the right places. They are the starting point for a mod: open one, paint over it, save it with the same name into your mod folder.

You get the same files from inside the app, which is usually easier: **Settings > Picture Flow > Graphic mods**, then either **New mod** (creates the folder and fills it) or **Export standard artwork** (writes them wherever you want). They are published here so you can look at them before installing anything, and so a mod pack can be built without opening Egle.

What each file is for, where it has to be transparent and what Egle keeps drawing on top: see [picture-flow-mods.md](../picture-flow-mods.md).

These files follow the app. If a future version changes how an object is drawn, this folder is refreshed with it, and your own mod keeps the look you gave it.
